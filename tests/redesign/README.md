# Проверки интерактивных макетов

Нужны Node.js 20+ и установленный Google Chrome. В этой папке выполните `npm install`, затем `npm test`. `npm run quality` проверяет темы, размеры экрана, доступность и большую таблицу. Проверки используют новый профиль браузера и локальный сервер; пользовательские данные браузера не затрагиваются.

- `regression.cjs`: 32 связных сценария для трёх вариантов.
- `audit-fixes.cjs`: 33 сценария для всех 12 замечаний повторного аудита; `BASE_URL` позволяет повторить их на опубликованной версии с отдельными профилями браузера.
- `edges.cjs`: модель данных, диапазоны дат, безопасный CSV, перетаскивание заголовков, буфер обмена, длинный текст, связи, увеличенный текст.
- `quality.cjs`: 132 сканирования axe (широкий и мобильный экран), 330 проверок ширины, замеры 487×24, закрепление и пагинация.

Результаты и снимки сохраняются в `.test-output/redesign` в корне репозитория; переменная `REPORT_DIR` меняет путь. Измерения скорости запускаются последовательно, без других тестовых профилей.
