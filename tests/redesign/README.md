# Проверки интерактивных макетов

Нужны Node.js 20+ и установленный Google Chrome. В этой папке выполните `npm install`, затем `npm test`. `npm run stress` проверяет большие таблицы, `npm run quality` проверяет темы, размеры экрана, доступность и большую таблицу. Проверки используют новый профиль браузера и локальный сервер; пользовательские данные браузера не затрагиваются.

- `regression.cjs`: 12 связных сценариев единого интерфейса Contour.
- `audit-fixes.cjs`: 11 сценариев для всех 12 замечаний повторного аудита; `BASE_URL` позволяет повторить их на опубликованной версии с отдельными профилями браузера.
- `edges.cjs`: модель данных, диапазоны дат, безопасный CSV, перетаскивание заголовков, буфер обмена, длинный текст, связи, увеличенный текст.
- `stress.cjs`: 6 сценариев на 95 782 записях, полный экспорт 50 000 строк, 30 проверок ширины и 7 сканирований доступности. Поддерживает `BASE_URL` для проверки опубликованной версии.
- `quality.cjs`: 44 сканирования axe (широкий и мобильный экран), 110 проверок ширины, замеры 487×24, закрепление и пагинация.

Результаты и снимки сохраняются в `.test-output/redesign` в корне репозитория; переменная `REPORT_DIR` меняет путь. Измерения скорости запускаются последовательно, без других тестовых профилей.


`npm run dictionaries` проверяет отдельный раздел справочников: 5 цепочек, 24 сочетания экранов, тем и ширин, 12 состояний доступности. Есть просмотр источников, переход к использующим значения записям, добавление контрагента, изменение списка, поиск и страницы для 115 значений, сохранение черновика и фильтров, защита при выходе и прямой адрес раздела. Для проверки публикации можно указать `BASE_URL`; отчёты сохраняются в `REPORT_DIR`.

## Сложные группировки

- `npm run grouping-model`: 70 проверок моделей групп, секций столбцов, сводной и дерева. Включены 50 000 строк, полные итоги, ISO-недели, диапазоны, совпадающие названия, валюты, единицы, циклы и предохранители сложности.
- `npm run grouping-browser`: 16 пользовательских цепочек новых механизмов в едином интерфейсе, включая клавиатуру, сохранение и ссылки, отмену перехода, фиксированные срезы, редактирование связанных записей, перенос групп, сворачивание секций, мобильную адаптацию и доступность.
- `advanced-regressions.cjs` воспроизводит пять найденных при независимой проверке ошибок сохранения контекста и поддерживает `CASE_FILTER` для целевого повтора.
- `columns-browser.cjs` дополнительно сохраняет снимки сложного реестра в двух темах и проверяет 8 сочетаний темы и размера экрана.

Проверка перетаскивания в `regression.cjs` использует новую явно обозначенную ручку рядом с полем. Центр строки настройки теперь занят выпадающим списком секции.

После выбора Contour функциональные цепочки запускаются в одном интерфейсе. Проверки защиты черновика сохраняют попытки перехода к другим таблицам, каталогу и набору данных. Удаление повторов для Register и Focus не исключает сценарии таблицы, доски, формы записи и настройки структуры.

## Главная и обучение

`npm run onboarding` проверяет главную и 7 обучающих маршрутов на 320, 390 и 1440 px. Сценарии выполняют реальные действия по подсветке и проверяют состав исходных записей, сохранение раскрытых уровней, связи, контекст родителей и отсутствие изменения данных. Отдельно проверяются старые ссылки, темы и доступность главной, пропуск, Escape, повтор, перезагрузка, восстановление потерянного элемента, защита черновика и изоляция настроек примеров.
