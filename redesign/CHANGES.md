# Исправления макетов по аудиту

Обновлены все три варианта: **Контур, Реестр и Фокус**. Изменения относятся к демонстрационным макетам на GitHub Pages. Рабочее приложение и PR #4887 не изменялись.

## Что теперь работает

| Замечание аудита | Результат |
|---|---|
| F01 — карточка теряла выборку | Переходы «Предыдущая» и «Следующая» и список соседей используют тот же порядок, что список. Возврат восстанавливает страницу и фокус записи. |
| F02 — структура не управляла формой | Общая модель задаёт названия, типы, обязательность, связи и порядок полей. Изменения применяются в карточке, таблице, фильтрах и новых записях. |
| F03 — действие затрагивало скрытый выбор | Поиск, фильтры, смена вида и страницы снимают выбор. Массовые действия дополнительно ограничены текущей выборкой. |
| F04 — не хватало инструментов конструктора | Добавлены редактирование ячеек, ширина столбцов, несколько ключей сортировки, два уровня группировки, CSV, копирование и дублирование выбранных записей, сохранённые виды, ссылки на виды, создание и удаление таблиц/полей, переходы по связям. |
| F05 — терялся фокус | Открытие карточки переводит фокус на заголовок; ошибки — на проблемное поле; возврат — на запись. После настройки таблицы фокус сохраняется на управляющем элементе. |
| F06 — слабый контраст подписи | Цвета боковой панели ограничены самой панелью; подписи структуры читаются в светлой и тёмной темах. |
| F07 — диапазон заменял прежнее условие | Поддерживаются несколько условий одного поля, диапазоны чисел/дат, множественный выбор значений, И/ИЛИ. Условия можно редактировать и удалять по одному. |
| F08 — мобильная доска показывала пустой этап | Выбор этапа согласован с фильтром. Доступны только этапы с результатами и вариант «Все этапы»; счётчики соответствуют показанным данным. |
| F09 — пустая дата и пробелы в названии | Пустая дата отображается как «Не указан». Пробельное название и незаполненные обязательные поля дают понятную ошибку; сохранение не имитируется. |
| F10 — вымышленная история | История содержит только фактические действия в демо. У новой несохранённой записи история пустая. |
| F11 — терялась основная колонка | В таблице закреплены заголовок, выбор строки и её название. Проверена горизонтальная и вертикальная прокрутка. |
| F12 — слишком много перерисовываемых данных | Монтируется только активный вариант. На странице 25, 50 или 100 записей; экспорт охватывает всю отфильтрованную выборку. Есть набор 487 × 24 для проверки объёма. |
| F13 — некорректная структура областей | На странице один основной блок; области навигации и настроек имеют различимые названия. |
| F14 — малые цели и обрезанный текст | Увеличены зоны частых действий, подписи меню переносятся. Проверены узкие экраны и симуляция двукратного увеличения текста. |
| F16 — столбцы настраивали другой экран | На доске есть собственные «Карточки»: выбор полей и порядок этапов. Сделки переносятся мышью или через доступный с клавиатуры выбор этапа. |

Длинное значение можно раскрыть непосредственно в таблице. Изменения данных можно отменять и повторять. Удаление связанных записей защищено проверкой ссылок. Несохранённые правки формы требуют явного отказа при уходе с неё.

## Проверка

- **32 из 32** связных сценариев прошли в Chrome: фильтры → карточка → возврат, изменение структуры → валидация формы, копирование/экспорт, сохранение после перезагрузки, доска и другие действия.
- **66** сканирований доступности: 3 варианта × 2 темы × 11 экранов. Автоматических нарушений не найдено. Дополнительные проверки изменённых состояний также прошли.
- **330** проверок ширины: 320, 390, 768, 1024 и 1440 px. Переполнения страницы не обнаружено.
- Набор **487 записей × 24 столбца**: в документе около **4 191 элементов**, на экране 50 строк. Смещение закреплённого названия и заголовка при прокрутке — **0 px**. Медиана поиска до следующего кадра в последнем прогоне — **82–84 мс**. Это локальный инструментальный замер, не гарантия скорости на любом устройстве.
- HTML-подобный пользовательский текст отображается буквально; CSV защищает текстовые значения от интерпретации как формул. Это проверка конкретных случаев, а не полный аудит безопасности.

Автоматические проверки не заменяют проверку экранным диктором и на физических телефонах. Увеличение текста проверялось через CSS, а не штатный zoom браузера.

## Границы результата

**F15 остаётся вопросом дальнейшей дизайн-проработки.** У направлений сохранены приоритеты: контекст карточки у Контура, плотность данных у Реестра, работа по этапам у Фокуса. Общие инструменты теперь позволяют сравнивать их на одинаковых рабочих задачах; это не три полностью разные архитектуры конструктора.

Расширен функционал существующих экранов. Вход, регистрация, файловый диспетчер, календарь, галерея, серверные ошибки и роли пользователей из старых описаний по-прежнему не представлены отдельными макетами. Сам аудит отделял эти пробелы покрытия от требования немедленно реализовать все такие экраны.

Записи и настройки сохраняются **в браузере посетителя**, отдельно для каждого варианта и набора данных. Ссылка на вид передаёт настройки стандартной таблицы, но не передаёт локальные записи или созданные таблицы. «Сбросить демо» возвращает текущий вариант к исходным данным.
