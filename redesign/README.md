# Интеграм: варианты редизайна

[Открыть интерактивные макеты](https://elbulm.github.io/crm/redesign/)

- [Контур](https://elbulm.github.io/crm/redesign/#contour) — спокойный рабочий интерфейс.
- [Реестр](https://elbulm.github.io/crm/redesign/#register) — плотное представление данных.
- [Фокус](https://elbulm.github.io/crm/redesign/#focus) — работа по этапам.

Это демонстрационные концепции, а не рабочая CRM. Данные вымышлены, изменения хранятся только в памяти страницы. Поддерживаются светлая и тёмная темы, мобильный экран, поиск, фильтры и редактирование демонстрационных записей. Серверные подключения отсутствуют.

Иконки: Lucide (ISC); лицензия в assets/LUCIDE-LICENSE.txt.

## Действия со столбцами

Клик по названию столбца переключает сортировку: по возрастанию, по убыванию, без сортировки. Стрелка рядом открывает действия конкретного столбца. Кнопка «Фильтры» позволяет одновременно задать условия для разных столбцов; активные условия отображаются над таблицей.

Заголовки столбцов можно перетаскивать. В панели «Столбцы» доступны перетаскивание, кнопки изменения порядка, флажки видимости и возврат к исходному виду. Основной столбец «Сделка» остаётся видимым, чтобы можно было открыть запись. На мобильном экране настройки доступны через ту же панель.
