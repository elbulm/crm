# Интеграм: варианты редизайна

[Открыть интерактивные макеты](https://elbulm.github.io/crm/redesign/)

- [Контур](https://elbulm.github.io/crm/redesign/#contour) — спокойный рабочий интерфейс.
- [Реестр](https://elbulm.github.io/crm/redesign/#register) — плотное представление данных.
- [Фокус](https://elbulm.github.io/crm/redesign/#focus) — работа по этапам.

Это демонстрационные концепции, а не рабочая CRM. Данные вымышлены, изменения хранятся только в памяти страницы. Поддерживаются светлая и тёмная темы, мобильный экран, поиск, фильтры и редактирование демонстрационных записей. Серверные подключения отсутствуют.
