# Product

## Register

product

## Users

Primary users are partner integrators who deploy catalog matching for a new client without editing Integram queries or asking the template author for help. Secondary users are the client's business operators who upload two catalogs, review ambiguous pairs, run bulk matching, and export results.

## Product Purpose

Turn the proven xcom catalog-matching case into a repeatable Integram template. A first-time integrator must be able to install it, map unfamiliar Excel columns, configure category-specific matching rules, run the first match, explain the score, and hand the workspace to an operator. Success is measured by independent deployments, deployment time, and the share of deployments that need template code changes instead of configuration.

## Brand Personality

Practical, trustworthy, and calm. Copy is direct and operational: it names the current step, the decision being made, and the consequence of that decision.

## Anti-references

- A generic low-code constructor that exposes Integram internals before the partner can complete the job.
- A marketing-style dashboard with decorative metrics, gradients, or unexplained automation claims.
- A single overloaded interface that mixes integrator setup with the operator's daily workflow.
- Silent AI decisions, hidden scoring rules, or error states that require the template author to interpret them.

## Design Principles

1. Keep the partner on a guided path from two files to the first reproducible run.
2. Reveal matching logic and consequences at the moment a setting is chosen.
3. Preserve the familiar operator workflow: upload, start, review, export.
4. Make every automatic proposal reversible and every saved decision traceable.
5. Degrade gracefully when optional services, especially LLM refinement, are unavailable.

## Accessibility & Inclusion

Target WCAG 2.1 AA for new screens. All steps and actions must be keyboard accessible, focus must remain visible, status must not rely on color alone, and motion must respect reduced-motion preferences. Russian is the primary interface language; labels must remain understandable without platform-specific jargon.
